# ponytail-skill

懒惰资深工程师模式（WorkBuddy 技能版）：最少的代码解决问题，省 token。

- 安装：放到 `~/.workbuddy/skills/ponytail/SKILL.md`
- 核心内容见 [SKILL.md](SKILL.md)
- 改编自 [DietrichGebert/ponytail](https://github.com/DietrichGebert/ponytail)（MIT），实测：代码量 -54%、token -22%、成本 -20%

> 2026-08-31：本仓库用于验证 WorkBuddy 环境 git 传输层修复（openssl TLS 后端 + 凭据管理器）。
